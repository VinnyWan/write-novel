## Context

`write-novel-setup` Phase 1.5 配置向导使用 `AskUserQuestion` 收集用户偏好。该工具硬限制每个问题最多 4 个选项、最多 4 个问题。当前实现中：

- **Q3 目标平台**：5 个选项（起点/番茄/晋江/知乎盐言/其他），超限 1 个
- **Q5 题材/流派**：9 个选项（8 个热门题材 + 其他），超限 5 个

两者均触发 `InputValidationError: Too big: expected array to have <=4 items`。

## Goals / Non-Goals

**Goals:**
- Q3/Q5 的每次 `AskUserQuestion` 调用选项数 ≤4
- 保持完整题材覆盖，不丢失任何 genre-catalog.md 中的选项
- 保持用户交互流畅，不显著增加点击次数

**Non-Goals:**
- 不修改 `AskUserQuestion` 工具本身的限制
- 不修改 genre-catalog.md 的题材列表
- 不改变 `.story-config.json` 的存储格式

## Decisions

### D1: Q3 目标平台 — 合并末位选项

将 5 选项合并为 4 选项：**起点 / 番茄 / 晋江 / 其他**。「知乎盐言」合并入「其他」，用户选择「其他」后在文本输入中写明具体平台。

**备选方案**：拆成两轮选择 → 过度复杂，5 选 1 的场景不需要两级交互。

### D2: Q5 题材/流派 — 两级级联选择

第一级「题材大类」（≤4 选项），第二级「具体题材」（≤4 选项，根据第一级动态展示）。

**题材大类分组**（4 选项）：

| 大类 | 包含题材 |
|------|---------|
| 都市/现代情感 | 追妻火葬场、霸总/甜宠、世情、小三/婚恋 |
| 玄幻/仙侠/武道 | 仙侠/玄幻、凡人流、都市高武 |
| 重生/穿越/历史 | 重生复仇、历史/架空历史、死人文学 |
| 更多题材 | 脑洞文、同人流派、文娱/娱乐圈、规则怪谈、长生流、其他 |

每个大类下的具体题材 ≤4 项，确保第二轮 AskUserQuestion 不超限。

**备选方案**：直接砍到 3 个热门题材 + 其他 → 失去题材覆盖度，与 genre-catalog.md 脱节。

## Risks / Trade-offs

- [风险] 两级选择增加一次交互 → 缓解：题材选择是一次性配置，多一次点击换来完整覆盖是合理 trade-off
- [风险] 大类划分可能引起用户对分类的疑问 → 缓解：每个大类附带典型题材提示，用户按自己故事核心判断即可
