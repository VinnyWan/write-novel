## Why

当前写长流程虽然覆盖了从选题到正文的完整链路，但五个关键创作环节存在"有壳缺核"的问题：初始化只部署基础设施不产出世界观内容，角色设计分散在多个 Phase 缺乏集中的人物羁绊构建，大纲层缺少主线/支线的显式分离，细纲的事件-冲突-转折点结构不够明确，正文写作与细纲的逐段对应关系不够紧密。这导致创作者在 AI 辅助下仍然是"写到哪算哪"，缺乏体系化的创作骨架。本次增强将这五个环节结构化嵌入现有流程，让 pipeline 从"能跑通"升级为"能出好故事"。

## What Changes

- **初始化阶段增加世界观构建**：在 story-setup Phase 1.5 配置向导之后，新增世界观初始化环节，产出 `设定/世界观.md`（时代背景/地理/势力格局/力量体系）和 `设定/题材定位.md`（题材/风格/目标读者/对标作品），将原本分散在 story-long-write Phase 2 的世界观构建前移并固化。
- **角色设计环节结构化为独立 Phase**：在 Phase 2（核心设定）中将角色设计提升为独立子阶段，要求产出主角卡（身份/性格/动机弧线/语言风格）、核心配角卡（每人至少含身份/性格/与主角关系/功能定位）、人物羁绊图（角色之间的关系类型、冲突点、变化预期）。由 character-designer agent 集中执行，不再分散到 Phase 3b。
- **大纲层增加主线/支线显式分离**：在 Phase 3a（卷纲）中增加剧情线梳理环节，要求产出 `大纲/剧情线.md`（主线 1 条 + 支线 2-5 条，每条含起止卷/核心冲突/关键节点），卷纲和细纲必须标注每章推进了哪条剧情线。
- **细纲结构强化事件-冲突-转折点**：Phase 3b 细纲 frontmatter 增加 `event`（本章核心事件，1 句话）、`conflict`（冲突类型+冲突双方+冲突强度 1-5）、`turning_point`（是否为转折点，若是则注明转折类型：人物弧线/剧情方向/势力格局/世界观揭示），正文合约从原来的模糊字段变为可校验的三要素。
- **正文写作强化细纲-正文逐段映射**：在 Phase 4 Stage B（Prewrite Gate）增加细纲拆段检查——将细纲的事件/冲突/转折点拆分为 3-6 个写作段落，每段标注预期字数/叙事功能（铺垫/推进/爆发/余韵），Stage C 正文执行时按段输出，Stage E（Postwrite Gate）校验段落覆盖率。

## Capabilities

### New Capabilities

- `world-building-on-init`: 初始化阶段的世界观构建——在 story-setup 中产出世界观设定和题材定位文件，确立故事的基础时空框架。
- `character-design-centralized`: 角色设计集中化——独立的角色构建 Phase，一次性产出主角/配角/羁绊图，不再跨 Phase 分散。
- `plot-thread-tracking`: 剧情线追踪——主线/支线显式分离，在卷纲、细纲、正文三层标注剧情线推进状态。
- `chapter-event-structure`: 章节事件结构——每章细纲包含事件/冲突/转折点三要素，作为正文合约的核心校验项。
- `outline-driven-segmented-writing`: 细纲驱动的分段写作——细纲拆段→逐段写作→段落覆盖率校验的闭环。

## Impact

- **受影响 skill**：`story-setup`（增加世界观初始化 Phase）、`story-long-write`（Phase 2-4 结构调整）
- **受影响 agent**：`story-architect`（世界观构建 + 剧情线设计）、`character-designer`（角色集中化设计 + 羁绊图）、`narrative-writer`（细纲驱动分段写作）、`reviewer`（新增三要素校验）
- **受影响模板**：`设定/世界观.md`、`设定/题材定位.md`、`设定/角色.md`、`大纲/剧情线.md`、`大纲/细纲_第X章.md`
- **风险**：初始化时间变长（原本 3 步变 4 步），但换来的是后续 Phase 加载的上下文更精准，总体效率不降。角色设计集中化可能使 Phase 2 时间显著增加，缓解方式为按字数规模分级（100 万字以下简化角色卡）。
- **依赖**：依赖现有 `story-setup` 和 `story-long-write` 的稳定流程作为基础，本次变更在其上增量增强，不破坏现有合约。
