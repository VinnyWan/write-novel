# 工作流总览

本目录是 write-novel 的流程事实源。CLI 和 Skill 只读取、校验、派生这些 Markdown 文件，不把写作流程硬编码在脚本里。

## 流程入口

| 流程ID | 文件 | 适用场景 | 推荐入口 | 输出物 |
|---|---|---|---|---|
| daily-writing | [[工作流/日更续写]] | 日更、续写、继续写下一章 | `python scripts/main.py state` | 章节草稿、摘要、状态更新 |
| review-deslop | [[工作流/审稿去味]] | 审稿、去 AI 味、复核 | `write-novel-review` / `write-novel-deslop` | 审稿意见、去味稿、复核结论 |
| chapter-commit | [[工作流/章节提交]] | 正文完成后的续航闭环 | `python scripts/main.py continue` | 章节文件、摘要、伏笔状态、备份 |
| rollback | [[工作流/章节提交]] | 提交失败或状态误写后恢复 | 手动恢复 `.bak` + doctor | 恢复记录 |
| release-check | [[工作流/脚本治理]] | 发布前检查和插件校验 | `python scripts/main.py validate-plugin` | 校验结果 |

## 约定

- 流程步骤写在 Markdown 表格中，脚本只解析表格。
- 状态写在 `工作流/当前任务.md` 和章节 Frontmatter 中。
- 风险写在 `工作流/风险清单.md`。
- 参考资料优先读取 `references/卡片/*.md`，JSON 只是兼容索引。
