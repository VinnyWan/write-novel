# 脚本治理

## 目的

脚本只能做 Markdown 解析、校验、派生物生成和文件系统执行。写作流程、状态、检查清单和参考资料必须优先写入 Markdown。

## 脚本清单

| 脚本 | 角色 | Markdown 合同 | 处理建议 |
|---|---|---|---|
| scripts/main.py | CLI 薄入口 | [[工作流/总览]] | 保留 |
| scripts/frontmatter_parser.py | Markdown Frontmatter 解析 | 全部 Markdown 合同 | 保留 |
| scripts/wikilink_resolver.py | Wikilink 解析 | 全部 Markdown 合同 | 保留 |
| scripts/prompt_builder.py | Prompt 派生生成 | [[工作流/日更续写]], [[references/索引]] | 保留 |
| scripts/state_updater.py | 章节提交执行器 | [[工作流/章节提交]] | 保留 |
| scripts/foreshadowing_tracker.py | 伏笔表执行器 | [[伏笔与线索回收池]] | 保留 |
| scripts/diagnostics.py | Markdown 合同校验和报告派生 | [[工作流/当前任务]], [[工作流/风险清单]] | 保留为薄校验器 |
| scripts/project_assets.py | 项目资产读取 | [[工作流/总览]] | 保留为共享读取器 |
| scripts/reference_store.py | 参考资料读取 | [[references/索引]] | 保留，优先读 Markdown |
| scripts/writing_state_machine.py | 阶段表读取与标记 | [[工作流/日更续写]], [[工作流/章节提交]] | 收敛为 Markdown 阶段表执行器 |
| scripts/dashboard.py | HTML 派生视图 | [[工作流/状态报告]], [[工作流/风险清单]] | 保留为派生器 |
| scripts/guardrails.py | 路径安全 | [[工作流/脚本治理]] | 保留 |
| scripts/plugin_validator.py | 发布校验 | [[工作流/脚本治理]] | 保留 |

## 新增脚本决策门禁

| 问题 | 如果答案是“是” | 处理 |
|---|---|---|
| 是否只是流程步骤、状态描述、检查清单？ | 是 | 写入 `工作流/*.md` |
| 是否只是写作知识、套路、术语？ | 是 | 写入 `references/卡片/*.md` |
| 是否只是一个新命令包装现有能力？ | 是 | 接入 `scripts/main.py`，不要新建模块 |
| 是否需要路径安全、批量文件读写或派生物生成？ | 是 | 允许脚本，但必须在本文件登记 |
| 是否已有 Markdown 合同和 CLI 表面验证？ | 否 | 不允许发布 |
