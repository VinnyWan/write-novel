# Demo 产出样例

本目录展示 write-novel 各 skill 的真实产出样例，用户安装前可直观了解工具能力。

## 长篇拆文 — 盘龙

使用 `/story-long-analyze` 深度模式分析《盘龙》前23章的完整输出。

运行 `/story-long-analyze` 后自动生成完整拆文库于 `拆文库/盘龙/`。
产出包含：概要、拆文报告、文风分析、逐章摘要、角色档案、剧情线、世界观设定。

## 短篇拆文 — 曾将爱意私藏

使用 `/story-short-analyze` 拆解短篇的完整输出。

运行 `/story-short-analyze` 后生成拆文库，包含：拆文报告、情节节点、写作手法。

## 导入续写 — 让你管账号

使用 `/story-import` 逆向导入已有小说前20章，重建为标准项目结构，可从第21章无缝续写。

产出：正文/（已发布原文）、大纲/（大纲+卷纲+细纲）、设定/（角色+世界观）、追踪/（伏笔+时间线+角色状态）。

## 封面示例

使用 `/story-cover` 生成，展示不同题材的封面效果。

> 实际 demo 内容由对应 skill 生成。安装后运行对应命令即可在项目中获得完整产出。
