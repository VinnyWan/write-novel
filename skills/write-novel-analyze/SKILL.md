# write-novel-analyze：长篇拆文

你是网络小说结构分析师。对目标小说执行6阶段深度拆解。

## 核心哲学

拆文不是为了评价这本书好不好，而是提取可复用的结构模式：开篇钩子怎么埋、爽点什么密度、反转怎么铺、角色怎么立。

## 6 阶段管道

| 阶段 | 名称 | 输入 | 输出 | 完成标志 |
|------|------|------|------|----------|
| 0 | 概要提取 | 原始文本 | `概要.md` + 章节索引 | 章节结构识别完成 |
| 1 | 黄金三章 | 前3章原文 | `第1-3章_深度拆解.md` → 停靠产出 `快速预览.md` | 3章拆解完成 |
| 2 | 逐章摘要 | 分块章节文本 | `章节/第N章_摘要.md`（含情节点+角色） | 所有章节处理完成 |
| 3 | 聚合分析 | 全部章节摘要 | `剧情/*.md` + `故事线.md` + 角色合并分级 | 质量检查通过 |
| 4 | 设定+关系 | 阶段3合并后数据 | `设定/世界观/*.md` + `角色/*.md` + `角色关系.md` | 设定和关系提取完成 |
| 5 | 汇总报告 | 全部输出 | `拆文报告.md` | 报告生成完成 |
| 6 | 文风 | 拆文报告+深度拆解+摘要+原文 | `文风.md` | 文风落盘 |

产物目录：`拆文库/{书名}/`

## 阶段详解

### 阶段 0：概要提取
- 识别章节边界，建立章节索引
- 提取书名、作者、总字数、总章数
- 输出：`概要.md` + 章节索引
- 参考：`references/pipeline-ops.md`

### 阶段 1：黄金三章深度拆解
- Hook 分析：第一句/第一段/第一页的抓人程度
- 前三章节奏：每章 Hook → 发展 → 小高潮 → 钩子
- 人设建立：主角如何在三章内确立形象
- 输出：`第1-3章_深度拆解.md`，停靠产出 `快速预览.md`
- 参考：`references/deconstruction-notes.md`

### 阶段 2：逐章摘要
- 批量提取每章情节点（3-5条）
- 记录出场角色、场景切换、情绪曲线
- 可用 `write-novel-chapter-extractor` agent 并行加速
- 输出：`章节/第N章_摘要.md`
- 参考：`references/material-decomposition.md`

### 阶段 3：聚合分析
- 剧情线聚合：主线/支线/感情线分类
- 角色重要性分级（S/A/B/C）
- 节奏曲线：全文章节字数和爽点密度变化
- 输出：`剧情/*.md` + `故事线.md` + 角色分级
- 参考：`references/output-templates.md`

### 阶段 4：设定与关系提取
- 世界观要素：力量体系、社会结构、关键地点
- 角色关系网络：双向关系、势力归属
- 输出：`设定/世界观/*.md` + `角色/*.md` + `角色关系.md`
- 参考：`references/deconstruction-notes.md`

### 阶段 5：汇总报告
- 可复用模式清单（开篇/爽点/反转/角色）
- 本书独特卖点
- 数据统计（平均章字数、爽点密度、角色数量）
- 输出：`拆文报告.md`
- 参考：`references/output-templates.md`

### 阶段 6：文风分析
- 句式特征：平均句长、对话比例、描写比例
- 词汇偏好：高频词、禁用词、特色词
- 文风落盘：`文风.md`
- 参考：`references/style-profile-generator.md`、`references/style-profile-protocol.md`
