# 日更续写

## 目的

在不丢设定、不乱伏笔、不污染上下文的前提下，完成下一章从准备到提交前的写作推进。

## 阶段表

| 阶段ID | 阶段名称 | 准入条件 | 输出物 | 失败恢复 | 下一步建议 |
|---|---|---|---|---|---|
| project_setup | 项目设置 | `全局写作状态.md` 与 `伏笔与线索回收池.md` 存在 | 可写作项目 | 运行 init 或补齐模板 | 创建或检查细纲 |
| outline_ready | 细纲准备 | 本章细纲存在，包含核心冲突、出场角色、硬性任务 | `分卷大纲/第{卷}卷_细纲_第{章}章.md` | 补写本章细纲 | 组装 Prompt |
| draft_done | 起草完成 | 已按细纲生成正文草稿 | `章节草稿/第{章}章_*.md` | 重新 assemble 并起草 | 进入审稿去味流程 |
| review_done | 审稿完成 | 多视角审稿已给出结论 | 审稿记录或章节 Frontmatter 标记 | 运行审稿流程 | 去 AI 味 |
| deslop_done | 去 AI 味完成 | 去味稿已复核，不破坏剧情事实 | 去味稿或章节 Frontmatter 标记 | 回到审稿意见修订 | 章节提交 |
| chapter_committed | 章节提交 | 正文可归档，标题和章节号确认 | 章节文件 | 修正标题/章节号后重试 | 更新摘要和全局状态 |
| global_state_updated | 全局状态更新 | 章节已提交，摘要已生成 | `全局写作状态.md`、`历史章节摘要/`、伏笔池 | 从 `.bak` 恢复后重跑 | 确认备份 |
| backup_done | 备份完成 | 关键源文件有备份或提交记录 | `.bak` 或 git diff | 手动复制关键文件 | 进入下一章 |

## 失败恢复

| 失败类型 | 处理方式 |
|---|---|
| 缺少细纲 | 停止写正文，先补 `分卷大纲/第{卷}卷_细纲_第{章}章.md` |
| 伏笔逾期 | 在本章细纲加入回收任务，或更新预计回收章节 |
| 角色状态不明 | 补角色卡片，再重新 assemble |
| 用户 override | 必须写入 `工作流/当前任务.md` 的 override 审计区 |
