# 日更续写流程

日更续写是串行批量模式。一旦进入此流程，同一批次内的"继续"/"续写"/"日更"都视为继续执行，不重新进入场景选择。

## 触发条件

- 项目已有正文（`章节草稿/` 目录非空）
- 项目已有历史摘要（`历史章节摘要/` 目录非空）
- 用户输入包含"日更""续写""继续写"关键词

## 流程

### 步骤 1：定位当前进度

1. 读取 `全局写作状态.md` Frontmatter → 获取 `当前分卷` 和 `当前章节`
2. 确认下一章要写的章节编号（当前章节 + 1 或用户指定）

### 步骤 2：加载上下文

1. 读取本章细纲：`分卷大纲/第{卷序号}卷_细纲_第{章序号}章.md`
2. 读取上章尾声：`历史章节摘要/第{上章序号}章_摘要.md` 的最后一段
3. 解析细纲中的 Wikilink → 加载角色状态和伏笔信息
4. 读取全局写作状态中的系统提示词和高压线
5. 检查逾期伏笔列表 → 追加回收提醒

### 步骤 3：写作

1. 组装 Prompt（系统提示词 + 上下文 + 硬性剧本任务 + 高压线 + 伏笔提醒）
2. 生成正文
3. 输出正文 + 简要说明（字数、主要推进的剧情点）

### 步骤 4：续航闭环

详见主 SKILL.md Phase 5 流程：
1. 章节存档到 `章节草稿/`
2. 生成摘要到 `历史章节摘要/`
3. 更新 `全局写作状态.md` Frontmatter
4. 追踪伏笔状态
5. 询问是否继续写下一章

### 步骤 5：继续或结束

- 用户说"继续"/"下一章"/"续写" → 重复步骤 1-4
- 用户说"结束"/"今天到这" → 退出日更流程
- 用户要求审查 → 先暂停日更，调用 `write-novel-review` 审查最新章

## 批量写作规则

- 不询问"是否继续"（除非细纲缺失或章节号冲突）
- 细纲缺失 → 暂停，提示用户补充细纲
- 章节号冲突（目标章节已有正文）→ 暂停，询问是否覆盖或跳过
- 批量上限：一次最多连续写 5 章，之后自动暂停询问是否继续
