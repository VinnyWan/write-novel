# 种田/基建写作框架

## 典型基建方向
- 种田流（开荒/种植/养殖）
- 领地建设流（从村到城到国）
- 宗门/学院经营流
- 科技树攀爬流（从零攀科技）

## 典型爽点模式
1. 废地变宝地（被嘲笑的地产出奇迹）
2. 建设成果震撼观众
3. 技术代差碾压竞争对手
4. 经济封锁被反向突破
5. 手下/弟子成长带来的成就感

## 常见节奏结构
- 15% 获得基地 / 发现废地
- 30% 基础建设 + 初具规模
- 30% 扩张期 + 外部挑战
- 25% 格局成型 + 文明层面的影响

## 常见毒点（避免）
- 建设过程跳过太多（读者爱看建设细节）
- 资金/资源无限无约束
- 外部冲突过少导致平淡
- 建设速度不符合设定逻辑
