# 系统流写作框架

## 典型系统类型
- 属性面板流（力量/敏捷/智力数值化）
- 任务奖励流（完成系统任务获得奖励）
- 抽奖/商城流（积分兑换能力或物品）
- 签到流（每日签到获得奖励）

## 典型爽点模式
1. 新手大礼包 / 开局赠送隐藏职业
2. 卡bug式操作让系统都懵了
3. 系统商城反向薅羊毛
4. 隐藏任务被触发，奖励超规格
5. 前世经验 + 系统 = 双重碾压

## 常见节奏结构
- 10% 穿越/重生 + 系统激活
- 25% 新手村发育 + 初见锋芒
- 30% 跨域竞争 + 势力建设
- 35% 系统真相 + 超脱规则

## 常见毒点（避免）
- 系统任务过于简单无挑战
- 奖励通胀太快导致战力崩坏
- 系统人格化太早或太啰嗦
- 主角被系统牵着走无主动性
