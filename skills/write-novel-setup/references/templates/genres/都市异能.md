# 都市异能写作框架

## 典型异能体系
- 元素系（控火/御水/雷电）
- 强化系（身体强化/速度/感知）
- 特殊系（时间/空间/预知）
- 传承系（古武/修真降维）

## 典型爽点模式
1. 普通人开挂碾压专业人士
2. 都市传说逐步成真
3. 低调做人高调打脸
4. 以能力破局商战/权斗
5. 跨圈降维打击

## 常见节奏结构
- 15% 能力觉醒 / 初识世界暗面
- 25% 都市游走 + 小圈子扬名
- 30% 组织冲突 / 势力格局重塑
- 30% 揭开世界真相 / 终极对决

## 常见毒点（避免）
- 能力太多太杂无主次
- 日常与现实脱节失去代入感
- 官方组织永远无脑反派
- 能力通胀导致战斗失去趣味
