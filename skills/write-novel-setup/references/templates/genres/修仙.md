# 修仙题材写作框架

## 默认力量体系
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫 → 真仙

## 典型爽点模式
1. 突破时天劫降临，全场震撼
2. 越级碾压，被嘲笑后实力打脸
3. 夺宝/秘境/遗迹争夺以弱胜强
4. 收服灵宠/神兵认主
5. 碾压曾经不可一世的天才

## 常见节奏结构
- 15% 拜入山门 / 初入修真
- 25% 同门争斗 / 秘境历险
- 30% 宗门大战 / 跨域争霸
- 30% 飞升成仙 / 大道之巅

## 常见毒点（避免）
- 频繁嗑药升级无代价
- 战力体系到后期崩坏
- 女主纯工具人
- 奇遇太多缺乏成长感
