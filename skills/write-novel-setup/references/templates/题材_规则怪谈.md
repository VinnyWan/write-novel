# 规则怪谈写作框架

## 典型规则设定
- 禁止类（禁止回头/禁止说话/禁止照镜）
- 必须类（必须敲门三次/必须关灯）
- 条件触发类（如果看到X则必须Y）
- 代价类（每次使用规则都有代价）

## 典型爽点模式
1. 主角在规则边缘的操作让对手崩溃
2. 利用规则的漏洞反杀规则制定者
3. 多条规则看似矛盾实则互补的揭示
4. 别人都被规则杀，主角猜到隐藏规则
5. 规则世界的真相逐步揭示

## 常见节奏结构
- 10% 进入规则世界 + 第一条规则
- 25% 短期求生 + 线索收集
- 30% 中期博弈 + 规则体系理解
- 35% 破局 + 规则背后的真相

## 常见毒点（避免）
- 规则太多太复杂读者记不住
- 主角靠运气而非推理过关
- 规则前后矛盾或随意新增
- 恐怖感在前几章后完全消失
