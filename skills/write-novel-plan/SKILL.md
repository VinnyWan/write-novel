# write-novel-plan：卷纲规划

你负责基于总纲增量细化卷纲/时间线/章纲，把新增设定写回设定集。不重做全局故事，不重写整份总纲或设定集。

## 执行原则

1. 只做增量补齐，不重写整份总纲或设定集。
2. 先锁定卷级节奏，再批量拆章。
3. 时间线是硬约束，所有章纲必须带时间字段。
4. 若发现总纲与设定冲突，先阻断，再等用户裁决。

## 阻断条件

- 总纲缺少卷名 / 章节范围 / 核心冲突 / 卷末高潮 → 阻断并请求用户补全。
- 发现设定冲突 → 标记 `BLOCKER`，等待用户裁决。
- 批量拆章时时间回跳且未标注闪回 → 阻断当前批次。

---

## 执行流程

### Step 1：加载项目数据并确认前置条件

读取 `全局写作状态.md`（Frontmatter + 正文）、`分卷大纲/` 下已有文件。
确认总纲包含：卷名、章节范围、核心冲突、卷末高潮。不足则阻断。

### Step 2：补齐设定基线

增量补齐，不清空不重写：
- `世界设定/世界观.md`：世界边界、社会结构、关键地点用途。
- `世界设定/力量体系.md` 或对应设定文件：境界链、限制、代价。
- `人物/*.md`：欲望、缺陷、初始资源与限制。

发现冲突先列出并阻断，等用户裁决。

### Step 3：选择目标卷并确认范围

确认卷名、章节范围（默认每卷 ~30 章）、核心冲突、特殊要求（视角/情感线/题材偏移）。

### Step 4：生成卷节拍表

产出 `分卷大纲/第{卷序号}卷_节拍表.md`：

- 中段反转（确无则写"无（理由：...）"）
- 危机链至少 3 次递增
- 卷末新钩子落到最后一章的章末未闭合问题

参考：`references/outlining/outline-structure.md`

### Step 5：生成卷时间线表

产出 `分卷大纲/第{卷序号}卷_时间线.md`：

- 明确时间体系与本卷时间跨度
- 有倒计时事件时列出并标记 D-N
- 所有章纲必须带时间字段

### Step 6：生成卷纲骨架

- 卷摘要、关键人物与反派层级
- 爽点密度规划、伏笔规划
- 跨卷一致性检查（非首卷时）

参考：`references/outlining/genre-volume-pacing.md`、`references/outlining/conflict-design.md`

### Step 7：批量生成章纲

批量规则：默认 `10章/批`；复杂题材 `8章/批`；简单 `12章/批`。

产出 `分卷大纲/第{卷序号}卷_详细大纲.md`，每章包含：

- 目标、阻力、代价、时间锚点
- 章内时间跨度、与上章时间差
- 爽点类型、涉及角色、伏笔操作
- 章末未闭合问题、钩子
- 结构化节点：**CBN**（1个）/ **CPNs**（2-4个）/ **CEN**（1个）
- 必须覆盖节点（最多4个）/ 本章禁区（不超过5条）

相邻章节 `CEN → 下一章 CBN` 必须逻辑承接。

参考：`references/outlining/chapter-planning.md`

### Step 8：把新增设定写回设定集

新角色 → `人物/`；新势力/地点/规则 → `世界设定/`。
若与总纲或既有设定冲突，标记 `BLOCKER` 并停止后续更新。

### Step 9：验证

必须通过：节拍表/时间线/详细大纲存在且非空、每章时间字段齐全、时间线单调递增、CEN→CBN 承接、BLOCKER=0。

### Step 10：更新状态

更新 `全局写作状态.md` Frontmatter：`当前卷`、`卷规划完成` 字段。
