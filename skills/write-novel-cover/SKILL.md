# write-novel-cover：封面生成

本 skill 负责根据小说设定生成封面设计提示词，配合外部图片生成工具（DALL-E / Midjourney / Stable Diffusion）使用。

## 流程

1. 读取 `全局写作状态.md` → 获取书名/主角信息
2. 读取 `世界设定/世界观.md` → 获取世界观类型和时代背景
3. 读取主角卡片 → 获取主角外貌特征

## 提示词生成

根据题材类型生成对应风格的封面提示词：

| 题材 | 风格关键词 | 色彩倾向 |
|------|-----------|---------|
| 修仙/玄幻 | 仙气、云海、古风、灵气 | 青蓝、金色、紫色 |
| 都市/现代 | 都市夜景、现代感、简约 | 冷灰、霓虹、黑白 |
| 科幻/末世 | 科技感、废墟、未来 | 深蓝、银白、暗绿 |
| 历史/架空 | 古建筑、战场、典雅 | 赭石、朱红、墨绿 |

## 输出格式

输出可直接投喂给图片生成工具的英文/中文 Prompt，包含：
- 主体（主角/核心场景）
- 风格（题材对应风格）
- 构图（视角/布局）
- 色彩（主色调）
- 文字（书名排版位置）

## 注意

本 skill 不实际生成图片，仅输出设计提示词。图片生成需配合外部工具。
