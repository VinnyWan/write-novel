# 章节提交

## 目的

把已审稿和去味的章节安全写入项目事实源，并同步摘要、全局状态、伏笔状态和备份。

## 阶段表

| 阶段ID | 阶段名称 | 准入条件 | 输出物 | 失败恢复 | 下一步建议 |
|---|---|---|---|---|---|
| chapter_file_written | 章节文件写入 | 标题、卷号、章号确认 | `章节草稿/第{章}章_{标题}.md` | 使用版本后缀避免覆盖 | 生成摘要 |
| summary_written | 摘要写入 | 章节文件存在 | `历史章节摘要/第{章}章_摘要.md` | 删除错误摘要后重跑 | 更新全局状态 |
| global_state_written | 全局状态写入 | 摘要已写入 | `全局写作状态.md` | 从 `.bak` 恢复 | 更新伏笔 |
| foreshadowing_written | 伏笔状态写入 | 本章细纲或摘要可解析 | `伏笔与线索回收池.md` | 手动修正伏笔表 | 备份确认 |
| backup_verified | 备份确认 | 关键文件已写入 | `.bak` 或 git diff 证据 | 手动复制关键文件 | 下一章 |
