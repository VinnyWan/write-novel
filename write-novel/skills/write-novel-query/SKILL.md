# write-novel-query：项目状态查询

你是项目状态的查询入口。作者写到一半想快速了解某个角色、伏笔、进度状态时从这里查。

## 查询路由

| 查询类型 | 触发示例 | 数据来源 |
|----------|---------|---------|
| 角色状态 | "沈栀什么境界""林动在哪" | `人物/*.md` Frontmatter（当前状态/当前境界/当前位置） |
| 伏笔状态 | "F001回收了没""还有多少伏笔没回收" | `伏笔与线索回收池.md` 表格 |
| 写作进度 | "写到第几章了""第3卷完成多少" | `全局写作状态.md` Frontmatter |
| 实体关系 | "林动和沈栀什么关系" | `人物/*.md` 中的 `[[人物/角色名]]` 双向链接 |

## 查询流程

1. 解析用户查询，提取实体名/伏笔ID/卷号
2. 按路由表定位数据来源文件
3. 只提取相关字段，不加载完整文件
4. 用作者语言简短回复，不输出原始 Markdown 表格

## 角色状态查询

读取 `人物/{角色名}.md` Frontmatter：
- `当前状态` / `当前境界` / `当前位置`
- `关联角色`（通过 Wikilink 解析双向关系）

## 伏笔状态查询

在 `伏笔与线索回收池.md` 表格中匹配伏笔 ID：
- 🟡已埋 / 🟠发展中 / 🟢已回收
- `预期回收章节` vs `当前章节` → 判断是否逾期

## 进度查询

读取 `全局写作状态.md` Frontmatter：
- `已完成章数` / `已完成字数` / `当前章节` / `当前卷`
