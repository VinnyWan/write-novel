# 项目模板文件清单

## 根目录模板

| 文件 | 用途 | 必须 |
|------|------|------|
| `全局写作状态.md` | 进度追踪 + 系统提示词 + 高压线 + 用户保护区 | 是 |
| `伏笔与线索回收池.md` | 伏笔生命周期三态追踪 | 是 |
| `README.md` | 项目说明（自动生成） | 否 |

## 目录模板

| 目录 | 用途 | 必须 |
|------|------|------|
| `人物/` | 角色卡片（`{姓名}.md`） | 是 |
| `世界设定/` | 世界观 + 力量体系 | 是 |
| `分卷大纲/` | 分卷大纲 + 单章细纲 | 是 |
| `章节草稿/` | 已生成章节正文 | 是 |
| `历史章节摘要/` | 每章 ~200 字摘要 | 是 |
| `全局设定/` | 跨卷全局设定（预留） | 否 |
