# 宫斗/宅斗写作框架

## 典型权力体系
- 后宫等级（嫔妃→贵妃→皇后）
- 世家门第（寒门→世家→皇族）
- 宅院结构（妾室→正妻→掌家）
- 朝堂后宫联动

## 典型爽点模式
1. 被欺凌后布局反击让对方身败名裂
2. 一步步从底层爬到权力巅峰
3. 对方设置了死局，主角暗中化解
4. 隐忍多章后的大揭露/大翻盘
5. 智斗中棋高一着，让对方自食其果

## 常见节奏结构
- 15% 进入环境 / 初次被排挤
- 25% 站稳脚跟 + 小规模反击
- 30% 权力角逐 + 中BOSS击倒
- 30% 巅峰对决 + 最终赢家

## 常见毒点（避免）
- 冲突全靠丫鬟信口传话推动
- 主角靠男主光环解决问题
- 智斗太浅薄像小学级别的算计
- 爽点全靠打脸而缺智斗乐趣
