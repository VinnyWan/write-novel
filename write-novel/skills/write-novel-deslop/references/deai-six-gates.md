# 去 AI 味六关检测体系

正文完成后经六关检测。A/B/D 关可脚本自动化；C/E/F 关需 Agent 语义判断。

> 本文是 SKILL.md 的「六道 Gate 完整参考」：上半为**检测规范**（命中模式/正则/严重度），下半为**修复方法论**（星级优先级、白名单 schema、修饰词清扫、重复语义四类、句长混用、对话去腔调、结尾去升华）。SKILL.md 只保留 Gate 总览表与 AI 味等级→Gate 范围决策点，逐项执行细节见本文。

## 六关总览

| 关 | 名称 | 检测对象 | 检测方式 | 严重度 |
|----|------|---------|---------|--------|
| A | 禁词关 | 高频 AI 套话、禁用句式 | 脚本（词表匹配） | S1 — 命中即修 |
| B | 句式模式关 | 万能状语、固定句式模板 | 脚本（正则模式） | S2 — 命中 ≥2 触发中扫 |
| C | 心理外化关 | 内心戏是否外化为可见事件 | Agent 判断 | S2 — 大段心理独白降级 |
| D | 节奏单调性关 | 段落/句子长度分布、情绪变化密度 | 脚本（统计） | S3 — 连续单调段落标记 |
| E | 对话自然度关 | 对话是否有潜台词、角色声音差异 | Agent 判断 | S2 — 千人一面降级 |
| F | 总结体关 | 章末是否有总结升华/上帝视角评判 | Agent 判断 | S1 — 出现即修 |

## A 关：禁词（词表匹配）

### 一级禁词（出现即命中，最高优先级）

| 毒级 | 句式 | 正则模式 |
|------|------|---------|
| ★5 | "不是……而是……" | `不是.{1,20}而是` |
| ★4 | "，带着……" 万能状语 | `，带着.{1,30}(?:的\|之)` |
| ★4 | "声音不大，却带着……" | `声音不大.{0,10}却带着` |
| ★4 | "他/她知道……" 告知式 | `[他她它我你][知道明白清楚懂得].{1,30}[了。]` |
| ★3 | "仿佛/犹如/宛若……一般" | `(?:仿佛\|犹如\|宛若).{1,30}一般` |
| ★3 | "眼中闪过一丝……" | `眼中闪过.{1,15}(?:的\|之\|，\|。)` |
| ★3 | "嘴角勾起一抹……" | `嘴角勾起.{1,15}(?:的\|笑\|，\|。)` |
| ★3 | "心中涌起一股……" | `心中涌起.{1,15}(?:的\|，\|。)` |
| ★3 | "心头一震" | `心头一震` |

### 二级禁词（频率触发）

| 词语 | 阈值 | 说明 |
|------|------|------|
| "眼神复杂" | ≥2 次/章 | 替代：描述具体眼神变化 |
| "命运的齿轮" | ≥1 次/章 | 禁用，太套路 |
| "心猛地一沉" | ≥1 次/章 | 替代：写身体反应 |
| "深刻变化" | ≥1 次/章 | 太抽象 |
| "踏上新的旅程" | ≥1 次/章 | 禁用，结尾套话 |
| "这一切都说明" | ≥1 次/章 | 总结体 |
| "他终于明白" | ≥1 次/章 | 告知式 |
| "新的篇章" | ≥1 次/章 | 结尾套话 |
| "与此同时" | ≥3 次/章 | 论文体 |
| "不可否认" | ≥2 次/章 | 万能结论 |

### 万能比喻禁用

| 类型 | 禁用词 |
|------|--------|
| 身体部位万能 | "身体微微一震""瞳孔猛缩""呼吸一滞""心跳漏了一拍" — 每章每个角色≤1 次 |
| 万能动作 | "沉默了一下""顿了顿""叹了口气""摇了摇头" — 每章每个角色≤2 次 |

## B 关：句式模式（正则检测）

### 目标模式

| # | 模式 | 正则 | 说明 |
|---|------|------|------|
| B1 | 排比反问三连 | `(?:难道\|怎么\|为什么).{5,30}[？?].{0,50}(?:难道\|怎么\|为什么).{5,30}[？?]` | 连续反问≥2 个 |
| B2 | 万能状语开头 | `^.{0,10}(?:随着\|伴随着\|在……[中下])\|在.{1,20}[中下]，` | 万能状语开头句 |
| B3 | 连续"了"字句 | `了[^。]{10,40}了[^。]{10,40}了` | 连续 3 句以上均以"了"结尾 |
| B4 | 论文体连接词 | `(?:然而\|与此同时\|不可否认\|显而易见\|毋庸置疑\|换言之)` | 不自然的高级连接词 |
| B5 | 抽象总结句 | `(?:这意味着\|这标志着\|这代表着\|这一切说明)` | 解释性总结 |

## C 关：心理外化（Agent 判断）

检测要点：
- 连续 200 字以上纯内心独白/心理描写 → S2
- 内心变化是否有外部可见事件（决定、误判、对话、物件变化）→ 无外部事件即 S3
- 情绪是否通过动作/对话/选择展示而非直接告知 → "他很愤怒"是告知，"他把杯子砸在桌上"是展示

---

## D 关：节奏单调性（脚本统计）

### 检测指标

| 指标 | 健康区间 | 警告区间 | 危险区间 |
|------|---------|---------|---------|
| 平均段落长度 | 30-60 字 | 60-80 字 | >80 字 |
| 段落长度方差 | >20 | 10-20 | <10 |
| 平均句子长度 | 15-30 字 | 30-45 字 | >45 字 |
| 对话段落占比 | 30-50% | 15-30% | <15% |
| 情绪变化密度 | ≥1 次/1000 字 | 0.5-1 次 | <0.5 次 |

检测方法：
- 段落长度：按 `\n\n+` 分段，统计每段字符数
- 句子长度：按 `[。！？]` 分句，统计每句字符数
- 对话比例：统计双引号包裹的段落占比
- 情绪变化：统计情绪关键词（怒/喜/惊/怕/悲/厌/爽/甜/暖/冷）出现频率

---

## E 关：对话自然度（Agent 判断）

检测要点：
- 不同角色对话是否有区分度（不看名字也能分辨谁在说话）
- 对话是否推进剧情或揭示性格（不为凑字数）
- 是否有潜台词（角色说的 ≠ 角色想的）
- 是否有"说明书式对话"（角色直接解释世界观/规则/关系变化）

---

## F 关：章末总结体（Agent 判断）

检测要点：
- 章末段落是否以总结/升华/上帝视角结束
- 禁止句式：
  - "这一切都说明……"
  - "他终于明白……"
  - "新的篇章开始了……"
  - "他不知道的是……"（空泛预告）
- 正确结尾：悬念、未完成动作、情感钩子、选择困境

## 三级强度控制

| 强度 | A 关 | B 关 | C 关 | D 关 | E 关 | F 关 |
|------|------|------|------|------|------|------|
| **轻量** | 一级禁词 | 跳过 | 跳过 | 跳过 | 跳过 | 章末总结体 |
| **标准** | 全部禁词 | B1/B4/B5 | 连续独白≥200字 | 段落/句子长度 | 说明书式对话 | 章末总结体 |
| **深度** | 全部禁词 | 全部 | 全部 | 全部指标 | 全部 | 全部 |

## 白名单机制

项目根可放置 `.deslop-whitelist` 文件，每行一个豁免词/正则：

```
# 角色口头禅豁免
眸色微沉
# 特定句式豁免
[他她]轻笑一声
```

脚本读取白名单后跳过匹配行。

### 白名单文件 schema

- UTF-8 编码，一行一个词
- `#` 开头的行为注释；空行忽略；首尾空白 trim
- 大小写敏感（中文不区分）

### 匹配规则

扫描时若禁用词命中段对应的子串在 `.deslop-whitelist` 中存在同样的子串，跳过该次告警。匹配方式与 banned-words.md 一致，使用子串扫描。

示例 `.deslop-whitelist`：

```
# 项目自定义豁免词（一行一个，# 开头为注释）
缓缓                # 主角"缓缓"是绰号，不算禁用词
仿佛山海             # 章名
深邃的山谷           # 设定地名
```

### 白名单适用场景

- 命中术语（如玄幻小说中的特定术语恰好匹配禁用词）
- 角色口头禅 / 绰号 / 设定专有名词
- 世界观专有名词
- 原文刻意使用的修辞手法

如果 `.deslop-whitelist` 不存在，不强制创建；在报告中说明可创建该文件。空白名单文件等同于无白名单。

# 修复方法论（各 Gate 执行细则）

> 以下为各 Gate 的详细修复规则，无论 agent 还是主线程执行，均须遵循。

## 门禁 A：禁用词替换

加载 [banned-words.md](banned-words.md) 作为基础词表，同时加载 `references/methodology/banned-words-star-rating.md` 获取 1-5 星危险等级分类。检测时按星级优先级处理：5星（最毒句式）和 4星（动作修饰词）为最高优先级，出现必须替换；3星（表达/心理类）每章不超过 1 次；2星（判断/描述类）和 1星（连结/过渡类）标记并建议简化。

**保护规则优先级**：保留创作意图与剧情功能 > 去AI Gate。Gate A-F 只能改变表达方式，不能删除伏笔、钩子、角色特征、关键信息或必要转折；遇到冲突时改为降AI重写或标注 `[需复核]`。

替换规则：
- 禁用词 → 具体动作/细节描写
- 不能简单换成另一个形容词
- 要用"展示"替代"告诉"

示例：
- ❌ "眼中闪过一丝不易察觉的悲伤" → ✅ "他垂下眼"
- ❌ "深吸一口气" → ✅ "胸口起伏了一下"（或直接删掉，这个动作90%无意义）
- ❌ "嘴角勾起一抹冷笑" → ✅ "他笑了一下，没到眼底"

---

## 门禁 B：句式去套路

加载 `references/methodology/toxic-sentence-patterns.md` 获取 7 种最毒句式模式及检测优先级。检测优先级：模式一（"不是A而是B"）和模式二（"带着……的……"）为最高优先级，出现必须替换；模式三（万能感受）和模式四（"……仿佛……"）每章不超过 1 次；模式五（章末升华）在章末 200 字内扫码，出现即切除；模式六（过度修饰副词串）标记并简化；模式七（作者视角评价）改为场景/动作呈现。

### AI 高频句式速查表

| 句式 | 问题 | 替代方案 |
|------|------|----------|
| "不是A，而是B" | **最毒** 中文 AI 句式 | 直接写 B 或更自然的表达 |
| "...，带着..." | 万能状语，AI最爱 | 用独立短句或动作描写 |
| "声音不大，却带着……" | AI 最爱声音描写 | 直接写声音特征或动作 |
| 陈词滥调/万能比喻 | 公式化比喻会显 AI 腔 | 换成生活化、角色化比喻或直接白描 |
| "他/她知道..." | 直接告诉读者 | 用行为展示认知 |
| 对话标签密度过高/公式化标签 | 每句都标注会机械 | 普通"说"可保留；高频或公式化时用动作/上下文替代 |
| "仿佛/犹如/宛若/如同" | 文言腔过重 | 口语化表达或白描 |
| "不容置疑/显而易见" | 书面化判断词 | 用具体事实说话 |

### 修饰词清扫

检查物品/人物前面的形容词、定语、副词、指示代词、量词，多余即删。删除后阅读不影响才删；含义流失则改成简洁名词。

示例：
- "白色的药片" → "药片"
- "飞驰的汽车" → "汽车"
- "手里那截链子" → "链子"
- "多年的衣服" → "旧衣服"（保留含义）

形容词原则：一次只用一个形容词修饰或不修饰，不连用、不堆砌。

## 门禁 C：心理描写外化

本 Gate 采用「去AI三遍法」中的 Pass 1（去泛化）方法：将抽象情绪词替换为具体身体反应和动作，不直接告诉读者角色的情绪状态。

AI写的心理描写特征：直接陈述情绪。

替换策略：
- "他很紧张" → "他的手在抖"
- "她很愤怒" → "她一把掀翻了桌子"
- "他很害怕" → "他的腿在发抖，几乎站不稳"
- "她很伤心" → "她转过身去，肩膀微微颤动"
- "他感到一丝失落" → "他愣了一下，把手机放回口袋"

**重复描写去重**：当相邻段反复表达同一信息、同一动作或同一情绪时，按 Gate C/D 处理，不另开专项流程。

处理方法：
- 合并同一瞬间的重复描写，保留最能推动情绪或剧情的细节
- 如果原文把一个动作拆成"动作概述 → 感知细节 → 身体反应"，改成同一段连续画面
- 若合并后节奏过快，恢复原文中有功能的信息，或把既有信息改成更自然的动作/对话表达；不在原动作后追加描写层，也不新增原文没有的情节

示例：
- ❌ "他拿起笔。手在抖。笔尖又停住。"
- ✅ "他拿起笔，笔尖刚碰到纸就偏了，手腕压了两次都没压稳。"

### 重复语义四类

同一意思不重复表达，只留一个最合适且简洁的：

| 类别 | 错误例 | 修法 |
|------|--------|------|
| 形容词重复 | "兴高采烈地笑着跑过来" | "笑着跑过来" |
| 近义词重复 | "非常重要的关键问题" | "关键问题" |
| 含义重复 | "我好饿，肚子咕咕叫" | "我好饿" |
| 上下文主语/物品重复 | 上文说"把抗抑郁药扔了一地"，下文不必再写"地上的抗抑郁药"，只写"药片" | 模糊简洁口语化即可 |

### 多余场景/人物/物品描写

服务情节人物之外的修饰描写直接删。

示例：
- "游惑手里握着一把短刀，刀锋冷冽" → "游惑手里握着一把短刀"
- "手铐紧紧扣住两人的手腕，中间连着一截不算长的链条" → "手铐扣住两人的手腕，中间连着链条"
- "暴雪极地的考场里，风雪没有停下的意思" → "暴雪极地的考场里"

## 门禁 D：节奏打碎

AI写作的节奏问题：句式过于整齐、段落过于匀称。

**对称段落检测**：扫描连续 3 段以上的段落，若句数相同或句长结构相似（如"主语+状语+谓语+宾语"连续出现），标记为对称段落。

### 句长混用指导

- 长句（15字+）：用于复杂动作、场景描写，连续不超过 2 句
- 中句（5-14字）：用于叙事推进，主力句式
- 短句（1-4字）：用于强调、转折、情绪爆发点
- 混用比例建议：长句 10-20%，中句 50-70%，短句 20-30%

处理方法：
- 打断连续排比句（保留1-2个，删掉其余）
- 长句拆短句，在关键动作/情绪点用短句强化
- 偶尔用不完整句（口语感）
- 段落长短交错（不要每段都3-5行）
- 对称段落至少打碎一处（合并、拆分或改写其中一段）

---

## 门禁 E：对话去腔调

AI写的对话特征：每句话都信息完整、逻辑清晰、表达精准。

### 口语化注入指导

- 加入口语化表达（"嗯""哦""行吧""啧""靠""哈"）
- 适当打断对话（角色可以答非所问、话只说一半）
- 加入口误、重复、改口（"我不是那个意思——算了"）
- 不同角色用不同的口癖/惯用语

### 动作穿插指导

- 每 2-3 句对话至少插入一个动作（喝水、看别处、玩手指、站起来）
- 用动作替代"说道/问道"标签（"她喝了口水。'然后呢？'"）
- 动作要能传递潜台词（紧张→玩手指，不耐烦→看窗外）
- 删掉解释性对话（角色不会把自己的动机说清楚）

处理方法：
- 加入口语化表达（"嗯""哦""行吧"）
- 适当打断对话（角色可以答非所问）
- 用动作穿插对话（"她喝了口水。'然后呢？'"）
- 删掉解释性对话（角色不会把自己的动机说清楚）
- 确保遮住角色名后能区分是谁在说话（角色语言差异化）

---

## 门禁 F：结尾去升华

本章总结升华已在 `references/methodology/toxic-sentence-patterns.md` 模式五（章末总结升华）中详细覆盖。AI写作的结尾特征：总想总结、升华、点题。

处理方法：
- 删掉总结性语句（"这一夜注定无人入眠""从今天起一切都将不同了"等）
- 用动作/场景收尾，不要用感慨收尾
- 如果结尾有"他知道...""这一刻...""人生或许就是..."→ 基本可以删
- 章末 200 字自动扫码，出现总结升华句即切除
