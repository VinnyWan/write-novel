# 读者债务追踪

伏笔 = 对读者的承诺。埋下伏笔即产生读者债务，逾期未还 = 信任透支。

---

## 伏笔状态定义

| 状态 | 含义 | 触发条件 |
|------|------|---------|
| `pending` | 已埋入，等待回收 | 正文中出现伏笔线索 |
| `in_progress` | 正在逐步揭示 | 部分信息已透露但未完全揭开 |
| `resolved` | 已回收 | 伏笔揭示完成，读者获得"原来如此"时刻 |
| `overdue` | 逾期未回收 | 超过计划回收章 10 章以上仍未回收 |
| `abandoned` | 已放弃 | 剧情走向改变，伏笔不再适用（需记录原因） |

## foreshadowing.md 模板字段

### 字段说明

| 字段 | 说明 |
|------|------|
| ID | F + 三位数字，按埋入顺序递增 |
| 描述 | 一句话描述伏笔内容，不剧透揭示结果 |
| 类型 | `身份伏笔` / `能力伏笔` / `关系伏笔` / `事件伏笔` / `物件伏笔` / `信息伏笔` |
| 埋入章 | 伏笔首次出现的章节号 |
| 计划回收章 | 预计揭示的章节号（可填范围如 `020-025`） |
| 实际回收章 | 揭示时的章节号（揭示后填写） |
| 关联线索 | quest / fire / constellation |
| 状态 | 见上表状态定义 |
| 逾期 | `true` 当 当前章 > 计划回收章上限 + 10 且状态非 resolved |

---

## 逾期计算规则

```
overdue = (current_chapter - planned_reveal_max > 10) AND (status != "resolved")
```

- 计划回收章为范围时取上限
- 计划回收章为 `-`（未定）时不计逾期
- 逾期标记每章写前由 prewrite gate 自动检测

## 伏笔与线索绑定

| 线索 | 伏笔数量上限 | 逾期容忍度 | 说明 |
|------|------------|-----------|------|
| quest（主线） | 不限 | 15 章 | 主线伏笔可跨卷，逾期阈值更高 |
| fire（支线/感情线） | 5 个活跃 | 8 章 | 支线伏笔应在本卷内回收 |
| constellation（伏笔线） | 3 个活跃 | 5 章 | 伏笔线逾期阈值最严，短平快 |

---

## 伏笔回收质量检查

回收伏笔时检查：

- [ ] 读者能回忆起这个伏笔吗？（超过 30 章未提 → 回收前需轻量提醒）
- [ ] 回收方式与埋入时的"承诺"对等吗？（小题大做 = 欺诈；大题小做 = 浪费）
- [ ] 回收后产生新伏笔了吗？（好伏笔的回收同时埋下新伏笔）
- [ ] 连续 3 章以上只埋不收？（→ 提示优先回收而非新埋）
