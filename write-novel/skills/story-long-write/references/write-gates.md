# 三阶段写门校验

每章写作经过三道门，Agent 在 SKILL.md 流程中依次执行。

---

## Gate 1: Prewrite（写前校验）

**时机**：加载上下文后、开始写正文前

**检查项**：

| 检查项 | 方法 | 不通过处理 |
|--------|------|-----------|
| 章契约完整 | 读取 `大纲/Chapter-NNN.md`，确认 frontmatter 字段齐全 | 补充缺失字段 |
| 上下文加载 | 确认已读取上一章正文 + 当前卷契约 + 相关角色状态 | 补充加载 |
| 爽点密度预估 | 按题材参数计算本章应有 N 个微兑现，章契约 `payoff_density` 已填 | 提示补充 |
| 线索冲突检测 | 检查 `strand` 字段：若前一章同线索已连续达到上限（支线≥2、伏笔≥1），提示切换 | 提示或自动调整 |
| 伏笔逾期检测 | 读取 `追踪/foreshadowing.md`，有逾期伏笔时提示优先回收 | 提示 |

**输出**：prewrite 检查报告（通过/警告/阻塞），阻塞项必须解决才能开始写作。

---

## Gate 2: Precommit（提交前校验）

**时机**：正文写完后、正式落盘前

**检查项**：

| 检查项 | 方法 | 不通过处理 |
|--------|------|-----------|
| 字数达标 | `word_count` 对比 `target_words`（±20% 容忍） | 标注偏差 |
| contract_nodes 完成 | 对比章契约的 CBN/CPNs/CEN 与实际正文内容 | 标注未完成项 |
| hook 有效 | 检查结尾段落是否包含有效的 hook（悬念/情绪/选择等，不含总结式结尾） | 标注弱结尾 |
| 格式合规 | 段落长度（无超长段）、对话独立、无多余空行 | 自动修复 |
| 去 AI 味 | 运行 `deai_check.py --json {正文文件}` 检查 A/B/D 关 | 报告问题数 |
| 投影一致性 | 正文中角色状态与 `追踪/characters.md` 一致（新增/变更已记录） | 标注差异 |

**输出**：precommit 检查报告，列出所有警告和错误。有阻塞性错误时禁止提交。

---

## Gate 3: Postcommit（提交后校验）

**时机**：正文落盘后

**检查项**：

| 检查项 | 方法 | 说明 |
|--------|------|------|
| 投影更新 | 增量更新 `追踪/` 下的投影文件 | state.md、progress.md、characters.md、foreshadowing.md |
| ledger 写入 | 在 `追踪/run-ledger.md` 追加一行 | 记录章号/时间/状态/字数 |
| 连续线索计数 | 更新 strand_sequence | 同线索递增，切换线索归零 |
| 备份 | 可选，复制正文到备份目录 | 备份目录：`备份/Chapter-NNN.md` |

**输出**：postcommit 完成确认，投影文件已更新。
