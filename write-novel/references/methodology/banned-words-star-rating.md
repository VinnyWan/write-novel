# 禁词分级体系（1-5 星危险等级）

## 5 星：最毒句式（必须替换）

这些句式是 AI 写作的核心指纹，出现即暴露，**必须全部替换**。

| 句式模式 | 示例 | 替换方向 |
|----------|------|----------|
| 不是A，而是B | "这不是恐惧，而是一种深入骨髓的寒意" | 直接写 "恐惧像刀子抵在后颈" |
| 带着……的…… | "带着一丝温柔的笑意" | "嘴角翘了翘" |
| 声音不大，却带着…… | "声音不大，却带着不容置疑的威严" | "他说得很轻。没人敢接话。" |
| 一种……的……油然而生 | "一种莫名的恐惧油然而生" | "他的手开始抖" |
| ……，仿佛…… | "他的眼神锐利，仿佛能看穿一切" | "他盯着她。她感觉自己被剥光了。" |

## 4 星：动作修饰词（高频出现时强制替换）

每千字出现 2 次以上必须替换。

| 词汇 | 危险原因 | 替换方向 |
|------|----------|----------|
| 蓦然 | 过度文艺的动作修饰 | 突然/一下子/省去 |
| 霍然 | 同上，且无口语场景 | 猛然/腾地/删 |
| 陡然 | 书面语 | 猛/一下/删 |
| 缓缓 | 过度使用的慢动作 | 慢慢/省去/用动作细节替代 |
| 微微 | AI最爱 | 省去/用具体幅度替代 |
| 轻轻 | 同上 | 省去/用动作声音替代 |
| 深深 | 过度心理化 | 省去/换算为身体反应 |

## 3 星：表达/心理类禁词（密度超标时替换）

每千字出现 3 次以上时替换。

| 词汇 | 危险原因 | 替换方向 |
|------|----------|----------|
| 仿佛 | 类比成瘾 | 像/好像/删（直接写） |
| 似乎 | 不确定成瘾 | 省去/改为肯定或否定 |
| 一股 | 量词模板 | "一阵"/省去 |
| 不由得 | 被动语态 | 省去/改为"不由得打量"→"盯着看" |
| 不禁 | 同上 | 省去/改为直接动作 |
| 忍不住 | 心理外化失败 | 改为身体反应 |
| 不知为何 | 作者偷懒 | 要么给原因，要么删 |
| 莫名其妙 | 同上 | 同上 |
| 一种……的感觉 | 模板化感受描写 | 改为具体感官细节 |

## 2 星：判断/描述类禁词（频次过高时建议替换）

每千字出现 5 次以上时建议替换。

| 词汇 | 危险原因 | 替换方向 |
|------|----------|----------|
| 毫无疑问 | 作者代读者判断 | 删/用事实证明 |
| 显而易见 | 同上 | 删 |
| 充满 | 万能描述词 | "充满力量"→"肌肉绷紧" |
| 无比 | 过度强调 | "无比强大"→给具体强度 |
| 极其 | 同上 | 同上 |
| 惊人的 | 不展示光说 | 用具体数字或对比 |
| 不可置信 | 同上 | 写围观者反应 |
| 震撼 | 告诉而非展示 | 写具体被震撼的行为 |

## 1 星：连结/过渡类（网文可适量保留，过量时删减）

这些是书面语过渡词，网文可接受少量使用，但连续出现时应打断。

| 词汇 | 建议 |
|------|------|
| 与此同时 | 可保留，但同一章不超过 2 次 |
| 随之而来 | 可保留，但不用在动作场景 |
| 紧接着 | 可保留，短句连接 OK |
| 就在此时 | 可用但不要每章都这样转折 |
| 然而 | 可保留，但不用在每段开头 |
| 于是 | 同上 |
| 因此 | 少用，网文读者不喜欢因果关系被解释 |

## 隐喻/比喻类（默认：全部删除）

AI 写作最爱用的万能比喻，出现即替换：

| 比喻 | 替换方向 |
|------|----------|
| 像潮水般 | 删/换角色生活经验相关的比喻 |
| 如闪电般 | 删/换具体速度描写 |
| 仿佛春风 | 删/换具体感官 |
| 如坠冰窟 | 删/写身体反应（发抖、冷汗） |
| 像刀子一样 | 删/写具体刺痛感 |
| 如同末日 | 删/写具体破坏场面 |

## 白名单系统

用户可在项目根创建 `.deslop-whitelist` 文件，每行一个词汇。白名单词汇跳过所有检测。

```
# .deslop-whitelist 示例
丹田
灵力
筑基
元婴
```

世界观专有名词不受禁词表限制。

## 使用方式

1. agent 读取此文件作为禁词匹配参照
2. 对照章正文逐项扫描
3. 输出按危险等级分组的禁词密度报告
4. 5 星 → 立即替换；4 星 → 高频时替换；3 星 → 密度超标时替换；2 星 → 建议替换；1 星 → 过量时删减
