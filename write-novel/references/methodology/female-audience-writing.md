# 女频写作方法

## 女频核心差异

女频读者追求**情感体验**而非力量体验。核心驱动力不是"变强"，而是"关系变化"。

## 四种核心情感模式

### 1. 追妻火葬场
- 结构：伤害 → 离开 → 觉醒 → 追回 → 反转
- 情绪弧：虐心 → 独立成长 → 爽感释放
- 关键：前期虐要够狠，后期追要够长，缺一不可

### 2. 死遁/假死
- 结构：铺垫压抑 → 假死/离开 → 真相延迟揭示 → 追悔
- 关键：死前细节要反复铺垫，死后反应要逐一描写

### 3. 先婚后爱
- 结构：被迫结合 → 日常相处 → 渐进升温 → 危机考验 → 确认
- 关键：升温节奏——每10章一个关系里程碑

### 4. 破镜重圆
- 结构：重逢 → 旧伤浮现 → 重新认识 → 和解 → 新生
- 关键：旧伤不是一次性揭示，要层层剥开

## 女频写作要点

### 情感描写
- 不只写"她哭了"，要写身体反应+心理活动+环境呼应
- 情感转折要有充分铺垫，不突兀

### 对话设计
- 不说破的对话比说破的更有张力
- "我不要了"比"我爱你"更动人
- 潜台词密度应高于男频

### 禁忌
- 不写"她也不知道自己怎么了"（心理描写懒惰）
- 不写"他眼中闪过复杂"（万能套路）
- 感情线推进不能全靠外部事件，必须有内心成长
