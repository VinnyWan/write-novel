# 跨书经验召回

## 核心理念

写过的东西不应被遗忘。每次开新书/新卷/新章节时，从已完成的创作中召回有效的模式和经验。

## 召回维度

### 1. 钩子召回
- 从过往章节中提取"高回头率"的章尾钩子类型
- 记录哪些钩子在哪种题材/情绪位置最有效
- 新章设计时优先复用已验证的钩子模式

### 2. 爽点模式召回
- 标记过去"高满意度"的爽点段落（读者反馈/自己判断）
- 提取其结构模式：铺垫长度 → 蓄能力度 → 释放节奏
- 新章的爽点按模式套用，内容替换

### 3. 对话模式召回
- 记录过去成功的角色对话格式（句长/节奏/潜台词密度）
- 同角色续写时保持一致
- 新角色的对话风格可参考过往相似角色

### 4. 失败经验召回
- 记录踩过的坑：被读者批评的情节、被编辑退回的部分
- 新章检查：是否重复了过去的错误模式

## 召回机制

### 写入时
- 每完成一卷/一本书，在 `追踪/run-ledger.md` 中记录本卷/本书的最佳模式摘要
- 格式：「本卷最佳钩子：第X章章尾的悬念型（预期→破灭→新悬念）」

### 召回时
- 开新书/新卷时，由 `write-novel-doctor` 或 `write-novel-long-write` 从 run-ledger 中提取模式记录
- Agent 读取并内化模式，但不原文复制
- 跨项目时，从 `references/methodology/` 读取通用方法论

## 召回检查清单

开新书/新卷前：
- [ ] 上本书最有效的 3 个钩子模式是什么？
- [ ] 上本书最成功的爽点结构是什么？
- [ ] 上本书读者最不满的是什么？（避开）
- [ ] 上本书哪个角色对话风格最受欢迎？
