# 最毒句式列表

AI写作最显著的句式指纹。下述句式在正文中出现即标记为"最毒句式"，必须替换。

## 模式一："不是A，而是B"结构

**危险度：最高**

这是 AI 写作的标志性句式，大量出现在 AI 生成的心理描写、环境描写、评价性文字中。人类网文作者基本不使用此结构。

```
❌ 这不是恐惧，而是一种深入骨髓的寒意
✅ 寒意从脊椎爬上来。他的手开始抖。

❌ 这个选择不是关于善恶，而是关于生存
✅ 活下来。善恶以后再说。
```

## 模式二："带着……的……"定语堆叠

**危险度：极高**

```
❌ 她带着一丝温柔的笑意点了点头
✅ 她嘴角翘了翘。点头。

❌ 声音不大，却带着不容置疑的威严
✅ 他说得很轻。没人敢接话。
```

## 模式三：万能感受模板"一种……的……"

**危险度：高**

```
❌ 一种莫名的恐惧油然而生
✅ 冷汗浸湿了他的后背。

❌ 一种说不清道不明的感觉涌上心头
✅ 他停住了。说不上来为什么。
```

## 模式四："……，仿佛……"类比成瘾

**危险度：高**

```
❌ 他的眼神锐利，仿佛能看穿一切伪装
✅ 他盯着她。她感觉自己被剥光了。

❌ 空气中弥漫着紧张，仿佛一根弦即将崩断
✅ 没人说话。呼吸声都听得见。
```

## 模式五：章末总结升华

**危险度：高**

```
❌ 这一夜，注定无人入眠。
✅ 远处传来狗叫。然后归于寂静。

❌ 他知道，从今天起，一切都将不同了。
✅ 他把那封信折好，放进怀里。

❌ 人生或许就是这样吧，总是在失去后才懂得珍惜。
✅ 删掉整句。让前面的动作自己说话。

❌ 从此，江湖上多了一个传说。
✅ 删掉。用场景结束。
```

## 模式六：过度修饰副词串

**危险度：中高**

```
❌ 他的身体不由自主地微微颤抖
✅ 他在抖。

❌ 一道声音突兀地、不容拒绝地响起
✅ 有人开口了。声音不大，所有人都听见了。
```

## 模式七：作者视角评价插入

**危险度：中**

```
❌ 他不知道的是，更大的风暴即将来临。
✅ 画面切换到远处：乌云正在聚集。

❌ 毫无疑问，这将是一场恶战。
✅ 他的手摸向刀柄。
```

## 检测优先级

1. **模式一** 和 **模式二** → 最高优先级，出现必须替换
2. **模式三** 和 **模式四** → 每章不超过 1 次
3. **模式五** → 章末 200 字扫码，出现即切除
4. **模式六** → 标记并建议简化
5. **模式七** → 标记并建议改为场景/动作呈现
