# 商业化核心方法

## 网文商业化的本质

网文是"情绪商品"。读者付费不是为文字，是为情绪体验。写作的核心问题不是"写什么"，而是"读者读完这段话后感受到什么"。

## 三条商业铁律

### 1. 前三章决定生死
- 第1章前500字：必须出现冲突或悬念
- 第1章结尾：必须有明确钩子（危机/悬念/欲望/情绪/选择）
- 前3章结束：必须让读者知道"主角要干什么"和"为什么我要看下去"

### 2. 每章都要有"爽点"
- 爽点 ≠ 打脸。爽点 = 读者期待的满足
- 每章至少1个明确的情绪兑现点
- 连续2章无兑现 → 读者流失风险

### 3. 追读靠钩子
- 章尾钩子是明天读者回来的唯一理由
- 5类钩子：危机/悬念/欲望/情绪/选择
- 同类型钩子连续使用不超过2章

## 题材商业属性速查

| 题材 | 核心情绪 | 爽点类型 | 付费点节奏 |
|------|---------|---------|-----------|
| 修仙 | 升级感+碾压感 | 境界突破/打脸/资源获取 | 每30章一个高潮 |
| 系统流 | 收获感+碾压感 | 系统奖励/任务完成 | 每15-20章 |
| 都市异能 | 碾压感+占有感 | 实力展示/财富获取 | 每20章 |
| 古言 | 期待感+安全感 | 关系进展/身份揭示 | 每25章 |
| 甜宠 | 温暖+占有感 | CP互动/身份确认 | 每10章 |
| 悬疑 | 好奇心+紧张感 | 线索揭示/反转 | 每5-8章 |

## 商业化写作检查清单

- [ ] 前三章是否在500字内建立冲突？
- [ ] 每章是否有至少1个爽点？
- [ ] 章尾是否有明确钩子？
- [ ] 付费前最后一章是否在高潮处断章？
- [ ] 是否有超过3章无主线推进？
