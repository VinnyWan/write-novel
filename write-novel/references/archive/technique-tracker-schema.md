# 功法状态追踪格式

`追踪/功法状态.md` 记录每个角色的功法技能树成长状态。

## 文件结构

```markdown
# 功法状态追踪

## {角色名}

| 功法名称 | 类型 | 品阶 | 掌握阶段 | 获得章节 | 升级节点 | 备注 |
|----------|------|------|----------|----------|----------|------|
| {功法名} | 功法 | 天阶 | 大成 | 第12章 | 第50章小成→第88章大成 | 主修功法 |
| {技能名} | 武技 | 3级 | 小成 | 第35章 | 第60章入门→小成 | 核心攻击手段 |
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 功法名称 | 功法/技能名称，与 `设定/功法技能/{名}.md` 对应 |
| 类型 | 功法 / 武技 / 法术 / 神通 / 秘术 / 禁术 |
| 品阶 | 对应力量体系的品阶标记 |
| 掌握阶段 | 入门 / 小成 / 大成 / 圆满 之一 |
| 获得章节 | 首次获得该功法/技能的章节号 |
| 升级节点 | 掌握阶段变化记录，格式：`第N章{旧阶段}→{新阶段}`，多次升级用顿号分隔 |
| 备注 | 自由文本，如"主修功法""已废弃""传承自师父" |

## 维护规则

- 每个角色一个 `## {角色名}` 二级标题，其下一个表格
- 无功法/技能的角色不建表
- 功法技能文件（`设定/功法技能/{名}.md`）中有"熟练度阶段"和"持有角色"字段，与本文档保持同步
- Phase 4 每章提交后检查本章是否涉及功法获得或升级，是则更新本文档
- 角色状态文件（`追踪/角色状态.md`）能力字段写 `详见 [功法状态](功法状态.md#角色名)`，不重复展开
