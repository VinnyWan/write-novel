# 上下文.md 三层结构格式规范

## 文件位置

`追踪/上下文.md`

## 用途

维护写作上下文的三层摘要，支持分级加载和 compact 恢复。

## 三层结构

```
# 上下文

## 精简层（最近 5 章详情）
<!-- 每章 ~200 字，用于写作新章节时快速进入状态 -->

### 第 N 章：{章名}
- 核心事件：{一句话}
- 情绪交付：{目标情绪} → {实际效果}
- 角色变化：{谁发生了什么状态变化}
- 新增伏笔：{伏笔ID + 一句话}
- 回收伏笔：{伏笔ID + 如何回收}

### 第 N-1 章...
### 第 N-2 章...
### 第 N-3 章...
### 第 N-4 章...

## 摘要层（10 章概要）
<!-- 每章 ~100 字，用于 Compact 恢复和跨卷跳转 -->

| 章节 | 概要 | 关键伏笔 |
|------|------|----------|
| N-9 | ... | ... |
| ... | ... | ... |
| N | ... | ... |

## 概览层（卷级）
<!-- 用于跨卷跳转时快速定位 -->

- 当前卷：第 X 卷 {卷名}
- 卷进度：已写 N/M 章
- 主角当前状态：{境界/身份/位置}
- 核心冲突阶段：{铺垫期/上升期/高潮前/高潮中/余波}
- 活跃伏笔数：N 个（其中逾期 N 个）
- 上次操作：{时间} - {操作描述}
```

## 更新规则

1. **每章完成后**：在精简层追加新章，将最旧章降级到摘要层
2. **Compact 前**：pre-compact hook 强制写入当前所有层
3. **Compact 后**：post-compact hook 读取此文件恢复状态

## 示例

```
# 上下文

## 精简层

### 第 12 章：拍卖会上的天价
- 核心事件：林动在拍卖会以 500 万灵石拍下神秘残图，引发各方势力觊觎
- 情绪交付：紧张 → 爽感释放（以碾压姿态震慑觊觎者）
- 角色变化：林动财富展示→被标记为肥羊；沈栀首次公开站在林动一侧
- 新增伏笔：F015 残图指向的上古遗迹位置；F016 黑衣人对林动的跟踪
- 回收伏笔：F008 沈栀的身份线索（通过拍卖会上的反应暗示）

...（继续 N-1 到 N-4）

## 摘要层

| 章节 | 概要 | 关键伏笔 |
|------|------|----------|
| 3 | 林动初入青云城，摆摊卖符被欺 | F001 青云城势力格局 |
| 4 | 反杀三煞帮，获得聚灵阵图纸 | F002 聚灵阵与古遗迹的关联 |
| ... | ... | ... |
| 12 | 拍卖会残图，各方觊觎，沈栀站队 | F015 遗迹、F016 跟踪 |

## 概览层

- 当前卷：第一卷《青云初啼》
- 卷进度：已写 12/30 章
- 主角当前状态：筑基后期，青云城散修，被标记为"肥羊"
- 核心冲突阶段：上升期（主角开始引起大势力注意）
- 活跃伏笔数：8 个（逾期 0 个）
- 上次操作：2026-06-14 11:05 - 完成第 12 章正文+审查
```
